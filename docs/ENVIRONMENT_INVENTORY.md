`ZEUS_UNOROUTER_CAPABILITIES` accepts only `stream`, `tools`, `structured_output`, `usage`, and `cancellation`. Zeus V1 defaults to the verified `glm-5.3` → `claude-opus-5` model pair, with `tools` and `structured_output` enabled. Custom model overrides must still be explicitly capability-verified. The provider adapter records serving model and credential metadata internally for operations, while the customer UI exposes only Zeus runtime usage and never secret material.

M4 sandbox and M5 OAuth/MCP provider variables remain configuration-dependent and must be added here only when the corresponding concrete provider implementation consumes them. Repository secrets must not be enumerated and copied blindly. Neon stores application data and encrypted CredentialVault envelopes, not arbitrary raw service secrets.
