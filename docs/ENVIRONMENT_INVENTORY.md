No secret values belong in this document. Server-only values must never use `NEXT_PUBLIC_*`.

`ZEUS_UNOROUTER_CAPABILITIES` accepts only `stream`, `tools`, `structured_output`, `usage`, and `cancellation`. `tools` and `structured_output` should be enabled only after the configured model has been verified to support them. The provider adapter treats `stream`, `usage`, and cancellation as protocol/runtime capabilities and records only whether the primary or fallback credential slot served a request, never secret material.

M4 sandbox and M5 OAuth/MCP provider variables remain configuration-dependent and must be added here only when the corresponding concrete provider implementation consumes them. Repository secrets must not be enumerated and copied blindly. Neon stores application data and encrypted CredentialVault envelopes, not arbitrary raw service secrets.
